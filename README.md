# Work Tracker - 互動式甘特圖專案

這是一個可部署到 GitHub Pages 的前端專案，具備：
- Frappe Gantt 拖曳式甘特圖
- Firebase Firestore 雲端儲存任務
- 可新增、更新進度與日期的專案追蹤工具

## 如何使用
1. 前往 [Firebase Console](https://console.firebase.google.com/) 建立專案與 Firestore 資料庫
2. 將 `app.js` 中的 `firebaseConfig` 替換為你自己的設定
3. 上傳整個專案到 GitHub，並開啟 GitHub Pages

## 技術堆疊
- Firebase Firestore
- Frappe Gantt.js
- 原生 HTML/CSS/JavaScript
